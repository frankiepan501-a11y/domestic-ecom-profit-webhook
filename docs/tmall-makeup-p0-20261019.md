# 天猫补单计算接入（2026-10-19）

## 授权范围
现有天猫生成器读取统一补单台，佣金随官方主订单结算，空包不计实物采购成本，保留平台收入/退款/净回款。仅天猫；不发卡、不重跑正式9月、不新增自动提醒。

## 实现
- app/makeup.py：现有App只读分页；主订单匹配；本金=计划已垫款-财务已到账追回=官方核实实付；佣金每主单一次。重复/未清/未知性质/跨月拆付/仅退款等异常停止，不猜金额。未结算佣金列资产待结转。
- task_runner.py：所有有天猫原件的生成都先取补单台，失败不继续生成。
- settlement_engine.py：空包成本和实物数量归零；费用分本金与佣金；官方净回款不扣站外垫款。中通Sheet2退件费仅加入天猫账单池，不影响抖音。
- presentation.py：保留官方原件数量/费用及补单调整桥接；原发卡验收仍有效。
- main.py：0.4.8；带鉴权的/profit/makeup-check仅验证实时Base与提供的官方结算集合，不写业务数据。
